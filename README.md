# Cowrie Honeypot Threat Intelligence Project

A cybersecurity research project focused on monitoring and analysing SSH/Telnet attacks using Cowrie Honeypot and Splunk Enterprise.

The project includes:

- Honeypot activity monitoring and log analysis.
- Source IP and authentication analysis.
- Attacker command and file-download investigation.
- Threat intelligence research and IOC identification.
- MITRE ATT&CK mapping.
- Weekly CTI reports and STIX 2.1 IOC collections.

**Technologies:** Cowrie, Splunk, Ubuntu, SPL, MITRE ATT&CK, STIX 2.1.

**Purpose:** Hands-on research in Cyber Threat Intelligence, Threat Hunting, and Security Operations.
